## Decisions I made (reversible)
- **Colima instead of Docker Desktop**, because Docker Desktop wasn't
  installed (QUESTIONS.md #1).
- **Friends' locations are read only through `visible_friends()`.** Live
  updates in the app (Phase 5) will use a Supabase Realtime Broadcast message
  that tells the app to refetch, not a direct subscription to the raw table.
  The raw table would bypass the precision rules.
- Indoor elevator boarding is modeled as 30 s each way, so one floor is faster
  by stairs, while a big floor change, or any trip under `avoid_stairs`, uses
  the lift.
